CraftTrace — 项目主页分享版 / Portable project page

打开方法
1. 完整解压压缩包，保留 CraftTrace 文件夹内的所有文件。
2. 双击 index.html，在 Chrome、Edge 或 Safari 中打开。
3. 不需要安装 Node.js、Python 或其他依赖，也不需要联网。
   请在电脑浏览器打开，不要在网盘/聊天软件的文件预览器中打开。

请发送整个 ZIP，不要只发送 index.html：视频和图片都在 media 文件夹中。
该版本包含完整两分钟视频对比，以及 Storyline、冬季 Graph、Departments 和 Timeline 展示。
交互演示使用预先制作的结果素材；Paper/Code 链接尚待正式发布。

How to open
Extract the entire archive, then open index.html in a desktop browser.
Keep assets and media next to index.html. No installation or server is needed.
Send the complete ZIP, not index.html alone. Use a browser, not a cloud-drive preview.

The folder can also be served directly by any static website host.
